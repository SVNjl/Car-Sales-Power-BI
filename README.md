Objective : To design and develop a dynamic and interactive dashboard that provides real-time insights into critical KPIs related to the car sales dataset. This dashboard will then help to make data-driven decisions, monitor progress and identify trends & growth opportunities effectively.

Methodology :-
1. Gathered all the required queries from the client, like what they want to know or see in this dataset's report.
2. Loaded the Excel file in the Power BI and checked all the column profiles and their distribution (like if any null values are there or not, column formatting, etc) in the power query.
3. Engineered necessary time intelligence DAX functions and for that, I created a separate DATE table and then built the relationship between main table and the date table.
4. Used different types of customized visualizations to visualize the intricate relationships among the various parameters/columns and enabled user driven parameters for visualization.
